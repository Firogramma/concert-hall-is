# СценаПлан — Информационная система организации работы концертной площадки

Веб-приложение для ведения расписания концертных мероприятий, контроля занятости залов и управления записями площадки. Проект выполнен в рамках учебной практики по ПМ.05 (МДК 05.02 «Разработка кода информационных систем»).

## Основные возможности
- Авторизация сотрудников площадки с проверкой учётных записей по БД (`users`).
- Просмотр списка мероприятий с поиском и фильтрацией по залам и статусам.
- Добавление, редактирование и удаление мероприятий с сохранением в реляционную БД SQLite (`sql.js`).
- Просмотр календарной занятости залов («Большой зал», «Малый зал», «Камерный зал»).
- Экспорт и импорт файла базы данных (`.sqlite`).

## Структура проекта
- `index.html` — разметка экрана авторизации, рабочей панели и модальных окон.
- `style.css` — оформление интерфейса, таблиц, карточек календаря и форм.
- `app.js` — клиентская логика приложения и выполнение SQL-запросов через `sql.js`.
- `schema.sql` — SQL-схема реляционной базы данных (`users`, `halls`, `events`).

## Запуск
Проект работает локально без установки веб-сервера (Apache/PHP не требуются): достаточно открыть `index.html` в браузере (или через Live Server в VS Code).
